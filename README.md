# もふもふ大放出 — HAMSTER FEVER

53枚のハムスター写真と、オリジナルのイラスト舞台を組み合わせた無料ガチャです。Flutter製。追加の実行時パッケージは使っていません。

## 遊び方と演出

1. 「ガチャを回す」で写真とレアリティを抽選します。
2. ほっぺのチャージ、リーチ、3つのリールの停止を経てPUSH待機になります。
3. PUSHで写真カード、カットイン、放射線、輪、紙吹雪が登場します。
4. 最近の6匹と、53枠の図鑑で集めたハムスターを確認できます。

舞台をタップすると応援が増えます。応援やスキップによって確率・結果は変わりません。抽選は開始時に1度だけ行い、結果の確定も1度だけです。レアリティはR 60%、SR 30%、UR 10%。写真は53枚から均等に選び、レアリティとは独立です。同じ写真を再び引くことがあり、図鑑にはその写真の最高レアリティを残します。

音は初期状態でオフ。上部のスピーカーボタンで短い合成効果音を有効にできます。隣のボタンで動きを控えめにできます。OSのアニメーション削減設定にも対応しています。バックグラウンドでは音と進行を停止し、戻ると続きから進みます。

## 保存と写真

Web版は同じブラウザ・同じオリジンのlocalStorageに図鑑と総抽選回数を保存します。プライベートモード、保存の禁止、サイトデータの削除、別端末への移動では引き継げません。保存不可の場合とネイティブ版ではセッション内のみ有効です。最近の6匹は訪問ごとにリセットされます。

既存プロジェクトの53個の写真URLを維持しています。写真は `kmc2400.github.io/hamster-images` の外部配信に依存します。読み込み中・読み込み失敗時はオリジナルのハムスターイラストを表示し、抽選・図鑑はそのまま利用できます。外部写真の公開・再利用条件は元の管理者に確認してください。

参考サイトの「予告 → リーチ → PUSH → 開放」という演出構成を応用しています。参考サイトの写真・音声・キャラクター・文章は取り込んでいません。舞台、キャラクター、紙吹雪はFlutterのCustomPainter、音はWeb Audioの合成音です。

## 開発

Flutter SDKがPATHにある状態で実行します。

```sh
flutter pub get
flutter run -d chrome
flutter analyze
flutter test
flutter build web
```

Web配布物は `build/web/`。`web/hamster_bridge.js` を含めて同じオリジンで配信してください。ネイティブ版はビルド・実機検証していません。

## ファイル構成

- `lib/main.dart`: 状態遷移、レスポンシブUI、カード、図鑑、ライフサイクル
- `lib/hamster_data.dart`: 53枚の写真URL、名前、レアリティ、抽選
- `lib/stage_art.dart`: 舞台・ハムスター・開放演出の描画
- `lib/platform_bridge.dart` と `platform_*.dart`: Web/ネイティブの保存・音声境界
- `web/hamster_bridge.js`: ブラウザ保存、合成効果音
- `test/hamster_gacha_test.dart`: 確率境界、演出フロー、結果の単一確定、スキップ、図鑑、320/375/768/1280pxレイアウト

別サイトに移す場合は `docs/effects-transfer.md` を参照してください。
