# 別サイトへの演出移植

## 移す単位

この実装では演出の見た目と抽選処理を分けています。別サイトで使う場合も、業務上の結果は演出開始時に確定し、演出はその結果を見せる役割に限定します。

| 段階 | 通常時間 | 表示・操作 | 参考箇所 |
| --- | --- | --- | --- |
| ready | 操作待ち | 舞台、主ボタン、最近の結果 | main.dart `_cabinet` |
| charge | 0〜1.67秒 | 充電、周囲のカプセル、応援 | `_spin` / MachinePainter |
| reach | 1.67〜3.8秒 | 揺れ、リールの段階停止、短い音 | `_sequence` / `_reels` |
| push | 操作待ち | 明確なPUSHボタン、スキップ | `_open` |
| reveal | 1.7秒 | カード拡大、輪、放射線、カットイン | RevealPainter |
| result | 次の操作待ち | 紙吹雪、履歴、再実行 | TheatrePainter |

動き削減時は前半を1.4秒、結果表示を0.35秒に短縮し、揺れ・周回・大きな開放演出を抑えます。スキップは抽選をやり直さず、同じ結果を即時確定します。PUSH・結果表示中もスキップを操作できます。

## デザイン調整点

`main.dart` 冒頭の `ink / cream / coral / mint / gold / plum` を対象ブランドに合わせます。`stage_art.dart` はCustomPainterで閉じているので、商品やキャラクターに合わせて絵を差し替えても状態遷移は維持できます。写真・名称・確率の変更は `hamster_data.dart` に集約します。

効果音は `web/hamster_bridge.js` の周波数・長さ・エンベロープを調整します。初期ミュート、ユーザー操作後の再生、背景タブでの停止、音声オブジェクトの解放を維持してください。音量を上げることで派手さを補う設計は避け、演出時間と画面内の強弱で調整します。

## 移植時の確認

- 同じ操作を連打しても結果が二重に保存されない。
- 開始直後・PUSH待機・結果演出中のどこでもスキップできる。
- 演出中の入力が抽選確率を変えない。
- アニメーション削減・ミュート・背景復帰でも結果に到達できる。
- 写真や保存領域が使えなくても操作できる。
- スマホの最小幅とデスクトップで、主ボタンと結果が読める。
- 保存キーを他のサービスと分ける。現在は `hamster-fever.collection.v1`。
